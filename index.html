PatchMatch

Histopathology Image Retrieval System

PatchMatch is a content-based image retrieval system for digital pathology. Using deep learning and similarity search, it enables pathologists to find visually similar whole slide images (WSIs) from large archives, supporting diagnosis, research, and education.

Built with PLIP, FAISS, and FastAPI, the system extracts features from tissue patches and performs fast similarity search across thousands of gigapixel pathology slides.
